# How well does entity search find fact-checks? A test collection and an evaluation on CimpleKG

This repository holds the code of the paper with this title.
Everything is in `paper-code/`: start from `paper-code/README.md`.
To run the AI relevance judges, follow `paper-code/judge/RUN-WITH-API.md` (the paper's run, through an API) or `paper-code/judge/RUN-ON-GPU.md` (the same open models on one's own GPUs).
Data is never in this repository: the scripts take the data folders as arguments.
